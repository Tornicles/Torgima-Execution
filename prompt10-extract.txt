WHAT THIS PROMPT BUILDS

Prompt 10 builds the Academy — the learning intelligence system that activates whenever a capability gap blocks execution. When a user fails a task due to a skill gap, the Academy does not just generate a generic lesson. It analyzes what specific capability is missing, builds a targeted learning path from the knowledge library, generates structured Academy tasks that teach through doing, and tracks skill progression so the same gap is never addressed twice without evidence of mastery. When Prompt 10 is complete, Bhudhi can teach while it executes.



THREE LAWS RESTATEMENT

LAW 1: Academy tasks are generated by the same Task Generation pipeline as normal tasks — they go through the Control Engine, TriggerRouter, Critic Agent, and OutputValidator. Academy tasks respect condition-based difficulty limits.

LAW 2: Skill progression is measured from Academy task completion and quality scores — deterministically. Bhudhi assesses skill gap severity but does not mark skills as mastered. Mastery requires evidence from the execution record.

LAW 3: Academy mode is triggered by the Continuous Task Guarantee Engine (CAPABILITY_GAP path). Bhudhi cannot independently decide to put a user in Academy mode. The trigger must come from a system-detected failure classification.
