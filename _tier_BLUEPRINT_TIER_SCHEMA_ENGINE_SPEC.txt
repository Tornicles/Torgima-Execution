1. SYSTEM OVERVIEW
The Blueprint Engine is the execution backbone of Torgima. It receives a completed, scored validation and automatically presents three blueprint tiers (Starter, Growth, Ultimate) for user selection. When the user picks a tier, the system generates the full blueprint chain â€” Plans, Seasons, Targets, Phases, Projects, Actions â€” then immediately initializes the Execution Loop: Signal â†’ Condition â†’ Enforcement â†’ Task Generation. This document defines the complete schema, engine architecture, and all connection points.

1.1 Master Flow
Validation Complete â†’ Tier Presentation Screen â†’ User Selects Tier â†’ BlueprintGenerationEngine â†’ Plans/Seasons/Targets/Phases/Projects/Actions Created â†’ BlueprintEngine.launch() â†’ Signal Init â†’ Condition Init â†’ Enforcement Package â†’ Task Generation â†’ Dashboard

5.4 Recommendation Logic
The system recommends one tier based on the validation scores:

function recommendTier(validation: Validation): BlueprintTier {
  const { feasibility_score, clarity_score, realism_score } = validation;
  const avg = (feasibility_score + clarity_score + realism_score) / 3;
  // Low scores â†’ start with Starter for structure
  if (avg &lt; 0.5) return BlueprintTier.STARTER;
  // Mid scores â†’ Growth for adaptation
  if (avg &lt; 0.75) return BlueprintTier.GROWTH;
  // High scores â†’ Ultimate for full optimization
  return BlueprintTier.ULTIMATE;
}
