WHAT THIS IS
A completely separate admin interface accessible only to you (the organization owner). It shows everything happening in the app: every user, every execution state, system health, Bhudhi usage, revenue intelligence, and support tools to intervene when a user is stuck. It is not part of the user-facing app — it is your organizational nerve center.
⚖ LAW: Admin access is protected by a separate ADMIN_SECRET environment variable. It has nothing to do with the user session system. If ADMIN_SECRET is missing, the admin panel returns 403 on every request.
⚖ LAW: Admins can READ everything. Admins can intervene in specific controlled ways. Admins CANNOT override signals, change conditions, or corrupt execution state — the same system laws apply.

ADMIN_SESSION_SECRET=&lt;32-char-random-string&gt;
ADMIN_2FA_SECRET=&lt;totp-secret-optional&gt;
Admin sessions are stored separately from user sessions in an admin_sessions table. Admin session TTL: 8 hours. No idle refresh.
1.2 Database: admin_sessions table
CREATE TABLE IF NOT EXISTS admin_sessions (
id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
admin_email TEXT NOT NULL,
created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
expires_at TIMESTAMPTZ NOT NULL,
ip_hash TEXT,
revoked BOOLEAN NOT NULL DEFAULT false
);
1.3 Admin route protection middleware
export async function requireAdminAuth(req, res, next) {
const adminSessionId = req.cookies[&quot;admin_session&quot;];
if (!adminSessionId) return res.status(403).json({ error: &quot;FORBIDDEN&quot; });
const session = await db.adminSession.findFirst({
where: { id: adminSessionId, revoked: false,
expires_at: { gt: new Date() } }
});
if (!session) return res.status(403).json({ error: &quot;FORBIDDEN&quot; });
next();
}
⚠ The /admin route MUST be completely isolated from user routes. Never reuse user session cookies for admin access. Never expose admin routes in the public API.
