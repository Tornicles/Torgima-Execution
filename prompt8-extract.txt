THREE LAWS RESTATEMENT
LAW 1: The event system processes state changes but never initiates signal calculations or condition assignments directly. Events carry payloads that downstream engines process. The Signal Engine and Condition Engine remain the sole calculators.
LAW 2: Dead letter queue items are logged and reviewed â€” they do not auto-retry with different data. Retries use the original event payload. Manual intervention is required for data-mutation retries.
LAW 3: Source-of-truth hierarchy: SignalRecord (most trusted) &gt; ConditionRecord &gt; WorldModel &gt; BhudhiLog. When systems conflict, higher-trust source wins. Bhudhi cannot override higher-trust sources.

model SystemEvent {
  id              String   @id @default(cuid())
  eventType       String   // See EVENT_TYPES below
  sourceEngine    String   // Which engine emitted this event
  userId          String?  // Null for system-wide events
  blueprintId     String?
  orderId         String?
  payload         Json     // Event-specific data
  idempotencyKey  String   @unique // Prevents duplicate processing
  status          String   @default(&quot;PENDING&quot;)
                           // PENDING | PROCESSING | COMPLETE | FAILED | DLQ
  processedAt     DateTime?
  retryCount      Int      @default(0)
  maxRetries      Int      @default(3)
  errorMessage    String?
  priority        String   @default(&quot;NORMAL&quot;) // LOW | NORMAL | HIGH | CRITICAL
  createdAt       DateTime @default(now())
  @@index([status, priority, createdAt])
  @@index([userId, eventType])
}

model DeadLetterQueue {
  id              String   @id @default(cuid())
  originalEventId String   // FK â†’ SystemEvent
  eventType       String
  payload         Json     // Original payload
  failureReason   String   // Why it failed
  failedAt        DateTime @default(now())
  retryCount      Int      // How many times it was attempted
  requiresManual  Boolean  @default(false)
  resolvedAt      DateTime?
  resolvedBy      String?  // &apos;SYSTEM&apos; | &apos;MANUAL&apos;
  resolution      String?
}

model IdempotencyRecord {
  id         String   @id @default(cuid())

  result     Json?    // Stored result (for safe replay)

  createdAt  DateTime @default(now())
  @@index([key])
}
