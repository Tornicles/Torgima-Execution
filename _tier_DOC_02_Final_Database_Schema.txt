1. Document Purpose

This document contains the complete Prisma schema for Torgima Phase 1. It defines all 42 tables, every column, every relation, every index, every constraint, and every enum. This is the single source of truth for the database layer.

This document is executed in Cursor by replacing the contents of prisma/schema.prisma with the full schema defined in section 4, then running the migration commands in section 5.

Rule: No engine, API route, or frontend component reads from or writes to the database using any column, table, or relation not defined in this document. If a column is needed and is not here, this document must be updated first.

5.3 Apply Partial Unique Indexes
Prisma does not support partial unique indexes in schema.prisma. After the migration runs, execute the following raw SQL against the database to add the six partial unique indexes:

-- One active blueprint per user
CREATE UNIQUE INDEX one_active_blueprint_per_user
  ON blueprints(user_id) WHERE active = TRUE;

-- One current signal per blueprint
CREATE UNIQUE INDEX one_current_signal_per_blueprint
  ON signal_snapshots(blueprint_id) WHERE is_current = TRUE;

-- One current condition per blueprint
CREATE UNIQUE INDEX one_current_condition_per_blueprint
  ON conditions(blueprint_id) WHERE is_current = TRUE;

-- One current enforcement package per blueprint
CREATE UNIQUE INDEX one_current_enforcement_per_blueprint
  ON enforcement_packages(blueprint_id) WHERE is_current = TRUE;

-- One current state memory per blueprint
CREATE UNIQUE INDEX one_current_state_memory_per_blueprint
  ON state_memory(blueprint_id) WHERE is_current = TRUE;

-- One current domain per blueprint
CREATE UNIQUE INDEX one_current_domain_per_blueprint
  ON domain_history(blueprint_id) WHERE is_current = TRUE;

Save this SQL as scripts/apply-partial-indexes.sql and add it to package.json:
"db:partial-indexes": "psql $DATABASE_URL -f scripts/apply-partial-indexes.sql"

6. Transaction Rules

7. Seed File

Create prisma/seed.ts with the following content. This populates feature flags and one test user for development.

import { PrismaClient } from "@prisma/client";
const prisma = new PrismaClient();

async function main() {
  // Upsert feature flags
  const flags = [
    { feature_name: "ai_enabled",                  enabled: true,  description: "Core AI" },
    { feature_name: "academy_enabled",             enabled: true,  description: "Academy tasks" },
    { feature_name: "team_mode_enabled",           enabled: false, description: "Phase 2" },
    { feature_name: "community_enabled",           enabled: false, description: "Phase 2" },
    { feature_name: "advanced_domains_enabled",    enabled: false, description: "Phase 2" },
    { feature_name: "advanced_frameworks_enabled", enabled: false, description: "Phase 2" },
    { feature_name: "ai_advanced_enabled",         enabled: false, description: "Phase 2" },
    { feature_name: "marketplace_enabled",         enabled: false, description: "Phase 2" },
    { feature_name: "predictive_signals_enabled",  enabled: false, description: "Ultimate only" },
  ];

  for (const flag of flags) {
    await prisma.featureFlag.upsert({
      where: { feature_name: flag.feature_name },
      update: {},
      create: flag,
    });
  }

  // Dev test user
  await prisma.user.upsert({
    where: { email: "dev@torgima.com" },
    update: {},
    create: {
      email: "dev@torgima.com",
      display_name: "Dev User",
      tier: "growth",
    },
  });

  console.log("Seed complete");
}

main()
  .catch(console.error)
  .finally(() =&gt; prisma.$disconnect());
